# Security Policy

## Supported Version

Security fixes are provided for the latest version on the `main` branch. Before reporting a problem, use `Settings` -> `System Upgrade` to confirm that the affected installation is current.

## Private Reporting

Do not report security vulnerabilities in a public GitHub issue.

Use the repository's **Security and quality** page and select **Report a vulnerability** to submit the report privately:

https://github.com/mr-ulusoy/OCI_migration_tool/security/advisories/new

Include:

- the installed commit shown under `Settings` -> `System Upgrade`
- the affected component and deployment model
- the potential impact
- reproducible steps or a minimal proof of concept
- relevant logs with secrets and customer information removed
- any known workaround

Never submit passwords, API keys, session tokens, private keys, runtime configuration archives, production OCI configuration, or customer data.

Reports are reviewed on a best-effort basis. No response time, resolution time, support commitment, or service-level agreement is provided.

## Public Discussion

After a fix is available, the maintainer may publish a GitHub security advisory with appropriate remediation and upgrade information. Do not publicly disclose an unresolved vulnerability before coordinated disclosure has been agreed.
