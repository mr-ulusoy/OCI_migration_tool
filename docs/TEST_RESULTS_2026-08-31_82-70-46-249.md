## Defects Found and Fixed

1. Quick Install displayed a generated admin password but did not persist it as documented. Fixed in `c5df364`; it is now stored at `~/oci-migrator-admin-password.txt` with mode `600` and is not printed in the final summary.
2. Production frontend dependencies contained high-severity Axios/form-data advisories. Fixed in `becc811`; installed production dependencies now report zero npm audit vulnerabilities.
3. Managed NFS exports mounted successfully but clients could not write with the service-owned directory permissions. Fixed in `93ce4e5` using controlled `all_squash` mapping to the OCI Migrator service UID/GID.

Backend tests, frontend lint/build, `make doctor`, external `/health`, and production dependency audit passed on the final installation.
