# Contributing

Thank you for helping improve Cloud Migration Console.

## Issues

Bug reports and feature requests are welcome through the repository's structured GitHub Issue forms. Search existing issues first and keep all submissions free of credentials, customer data, and sensitive infrastructure information.

Security vulnerabilities must be reported privately according to [SECURITY.md](SECURITY.md).

## Code Contributions

Code contributions and pull requests are not currently accepted. Use GitHub Issues for bug reports and feature proposals.

## Support Expectations

Issues and feature requests are reviewed on a best-effort basis. No response time, implementation commitment, maintenance commitment, or service-level agreement is provided.
